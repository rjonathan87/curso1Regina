🐛 ¿Por qué no funciona?

Así como un detective busca pistas para resolver un caso, un programador busca pistas para encontrar errores. Todos los programas tienen errores. La diferencia entre un principiante y un experto no es que el experto no cometa errores, sino que sabe cómo encontrarlos y corregirlos.

Sesión 1 Los 3 tipos de errores y cómo cazarlos
▼

🔴 Error 1: Error de sintaxis

Python no entiende lo que escribiste. Es como si hablaras español pero de repente dijeras "casa azul el volar rápido" — la gramática no tiene sentido.

❌ Error de sintaxis
nombre = input("¿Cómo te llamas?")
if nombre == "Regina" # ← FALTA :
    print("Hola profe")
✅ Solución: Agregar : al final del if. Python te dice exactamente la línea del error.

🟡 Error 2: Error de lógica

El programa funciona sin errores... pero hace algo diferente a lo que querías. Es el error más difícil de encontrar porque Python no te avisa.

❌ Error de lógica
# Quería contar del 1 al 5
for i in range(5):  # ← range(5) da 0,1,2,3,4
    print(i)         # Muestra 0,1,2,3,4 no 1,2,3,4,5
✅ Solución: range(1, 6) en lugar de range(5). Usa print() para ver qué valores está generando tu programa.

🟠 Error 3: Error de ejecución

El programa arranca bien pero se detiene a medio camino porque algo sale mal. El programa "explota" (crash).

❌ Error de ejecución
numero = input("Número: ")
resultado = 10 / int(numero)  # ← Si el usuario escribe 0, ¡CRASH!
print("El resultado es", resultado)
✅ Solución: Validar antes de dividir: if numero != 0: o usar try/except.

🔧 Las 3 herramientas del debugger

🖨️ Print()
Pon print("DEBUG:", variable) en medio del código para ver qué valor tiene cada variable en cada paso.
💬 Comentar
Pon # al inicio de líneas para desactivarlas temporalmente. Así aíslas qué parte del código causa el problema.
📖 Leer el error
Los errores de Python siempre dicen la línea exacta y el tipo de error. Léelos de arriba a abajo. La última línea es la más importante.

🔍 "El detective de errores"

Cada uno de estos programas tiene un error. Tu misión: leer el mensaje de error, encontrar la línea problemática y corregirla. Usa el editor de Python de la Unidad 3 para probar.

🔴 Error A — Sintaxis

¿Qué falta aquí?
edad = int(input("Tu edad: "))
if edad >= 18
    print("Eres mayor de edad")
else:
    print("Eres menor")

💡 Pista: mira la línea del if. ¿Qué tiene el if de Python que no tenga este?

🟡 Error B — Lógica

¿Qué imprime?
temperatura = 30
if temperatura > 20:
    print("Hace calor")
elif temperatura > 30:
    print("Hace mucho calor")

💡 Pista: ¿puede llegar a ejecutarse el elif si temperatura es 30? ¿No es 30 > 30?

🟠 Error C — Ejecución (crash)

¿Cuándo explota?
nota1 = float(input("Nota 1: "))
nota2 = float(input("Nota 2: "))
promedio = (nota1 + nota2) / 2
print("Tu promedio es", promedio)

💡 Pista: este programa NO tiene error técnico... pero ¿qué pasa si ingresas "hola" en lugar de un número?

🟢 Error D — Tu turno

Encuentra el error
print("Bienvenida al juego")
nombre = input("Nombre: ")
print("Hola, " + nombre
print("Vamos a jugar")

💡 Pista: cuenta los paréntesis en cada línea. ¿Todos están cerrados?

💡 Consejo final: Cuando tu programa no funcione, respira hondo. No es que "no sepas programar", solo es que aún no has encontrado el error. Con la práctica, cada vez los encontrarás más rápido. ¡Hasta los programadores más experimentados pasan el 50% de su tiempo debuggeando!
