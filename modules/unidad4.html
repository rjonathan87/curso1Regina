Sesión 1 ¡Hola, Scratch! — Primeros pasos
▼

¿Qué es Scratch?

Scratch es un lenguaje de programación visual creado por el MIT Media Lab. En lugar de escribir código con texto, arrastras y sueltas bloques de colores que se ensamblan como piezas de un rompecabezas. Es usado por millones de niños y principiantes en todo el mundo.

🔧 Bloques en Scratch → Conceptos de programación
🎬 Eventos (color amarillo) = "Cuando la bandera verde se haga clic" — el inicio del programa
⚙️ Control (color naranja) = condicionales (if) y bucles (repetir, por siempre)
💙 Movimiento (color azul) = mover el personaje, girar, ir a una posición
❤️ Variables (color rojo) = guardar datos como puntuación, nombre, etc.

🖥️ El editor de Scratch

El editor tiene 3 áreas principales:

  • Panel de bloques (izquierda): todos los bloques organizados por categoría de color.
  • Área de scripts (centro): aquí arrastras los bloques para armar tu programa.
  • Escenario (derecha): la ventana donde ves lo que hace tu programa.

🔀 Condicionales en Scratch

Así como en Python usamos if, en Scratch usamos el bloque "si… entonces" de color naranja (Control). Podemos preguntar cosas como "¿tocando el borde?", "¿tecla presionada?" o "¿número aleatorio?".

🧪 Sensores
• ¿tocando el borde?
• ¿tocando el color X?
• ¿tecla [espacio] presionada?
• respuesta a "preguntar"
🔀 Control
• si… entonces
• si… entonces… si no
• esperar hasta que…
• repetir hasta que…
💡 Conexión con Python
El bloque "si <tocando borde> entonces → rebotar" en Scratch es exactamente:
if tocando_borde: rebotar() en Python.
El concepto es el mismo, solo cambia la forma de escribirlo.

📊 Variables en Scratch

Así como en Python creabas variables con puntos = 0, en Scratch creas variables desde el bloque "Variables" (color rojo). Son ideales para guardar puntuaciones, vidas, nombres o cualquier dato que cambie durante el juego.

Scratch (visual)
[Variables] → "Crear una variable"
  → "puntuación"
[por siempre]
  [si tocando Canasta?]
    [cambiar puntuación por 1]
Python (equivalente)
puntuacion = 0
while True:
  if tocando_canasta():
    puntuacion += 1

🔁 Clonación

La clonación permite crear copias de un objeto mientras el juego se ejecuta. Es perfecta para: disparar balas, crear enemigos múltiples, estrellas que caen, etc.

💡 Flujo de clonación
1. Objeto original: "al hacer clic en bandera verde" → "por siempre → esperar 2 segundos → clonar"
2. Objeto clon: "al empezar como clon" → "por siempre → mover 10 pasos"
3. Cuando el clon toca el borde → "eliminar este clon"
