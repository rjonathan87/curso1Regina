Fase 2: Gestión de tareas 🟢

Usa una lista para guardar tareas. Puedes agregar, ver y marcar como completadas.

Gestión de tareas
tareas = []

def mostrar_tareas():
  if not tareas:
    print("No hay tareas pendientes 🎉")
  else:
    for i, t in enumerate(tareas, 1):
      print(f"{i}. {t}")
✅ Conceptos: listas, for, funciones, if/else

Fase 4: Frases motivadoras 🟣

Una lista de frases. Cada vez que el usuario elige esta opción, aparece una frase aleatoria.

Frases aleatorias
import random

def frase_motivadora():
  frases = [
    "¡Tú puedes con todo!",

    "La práctica hace al maestro",
    "Nunca dejes de aprender",

Fase 5: Diario personal 🔴

Guarda notas en una lista y permite verlas. Cada nota tiene fecha y hora.

Diario personal
from datetime import datetime

notas = []

def escribir_nota():
  texto = input("Escribe tu nota: ")
  momento = datetime.now().strftime("%d/%m/%Y %H:%M")
  notas.append(f"[{momento}] {texto}")
  print("Nota guardada ✅")
✅ Conceptos: import, datetime, listas, funciones

Fase 6: Minijuego "Adivina el número" 🟠

El clásico juego de adivinar un número entre 1 y 20 con intentos limitados.

Adivina el número
import random

def jugar():
  secreto = random.randint(1, 20)
  intentos = 5
  print("Adivina el número (1-20). Tienes 5 intentos.")
  while intentos > 0:
    n = int(input("Tu número: "))
    if n == secreto:
      print("¡Correcto! 🎉")
      return
    elif n < secreto:
      print("Más alto")
    else:
      print("Más bajo")
    intentos -= 1
  print(f"Se acabaron. Era {secreto}")
✅ Conceptos: random, while, if/elif/else, variables
