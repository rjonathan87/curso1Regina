¿Qué es Python?

Python es un lenguaje de programación creado en 1991 por Guido van Rossum. Se diseñó para ser fácil de leer y escribir. Hoy es uno de los lenguajes más usados del mundo: en YouTube, Instagram, Google y hasta en la NASA.

💡 Tu primer programa
En casi todos los lenguajes, el primer programa es mostrar "¡Hola, mundo!" En Python es muy simple:
Python
print("¡Hola, mundo!")

📦 Variables: guardar información

Una variable es como una cajita con nombre donde guardas datos. Puedes guardar texto, números y muchas cosas más.

Python — Variables
nombre = "Regina" # texto
edad = 15 # número entero
altura = 1.65 # número decimal

print("Me llamo", nombre)
print("Tengo", edad, "años")

🗣️ Input — preguntar al usuario

Con input() puedes hacer que tu programa le pregunte algo al usuario y guarde su respuesta.

Python — Input
nombre = input("¿Cómo te llamas? ")
print("¡Hola,", nombre, "!")

🔀 If / Else — tomar decisiones

En la Unidad 2 aprendiste sobre decisiones (SI/SINO). En Python se escribe con if y else.

If / Else
edad = int(input("Tu edad: "))
if edad >= 18:
  print("Eres mayor de edad")
else:
  print("Eres menor de edad")
⚡ Importante
input() siempre devuelve texto. Para números usa int() o float().

Los dos puntos ( : ) y la sangría (espacios) son obligatorios en Python.

Sesión 3 Bucles en Python — for y while
▼

🔁 For — repetir un número fijo de veces

El bucle for se usa cuando sabes cuántas veces quieres repetir algo.

For con range()
# Contar del 1 al 5
for i in range(1, 6):
  print("Número", i)
For con lista
# Recorrer una lista
amigos = ["Ana","Luis","Sofía"]
for a in amigos:
  print("Hola,", a)

🔄 While — repetir mientras algo sea cierto

El bucle while se usa cuando NO sabes cuántas veces vas a repetir, solo cuándo parar.

While — adivina el número
secreto = 7
intento = 0
while intento != secreto:
  intento = int(input("Adivina el número: "))
  if intento < secreto:
    print("Más alto")
  elif intento > secreto:
    print("Más bajo")
print("¡Correcto!")

📋 Listas — colecciones de datos

Una lista es como una mochila donde puedes guardar varios elementos. Se escribe entre corchetes [ ] separando los elementos con comas.

Python — Listas
materias = ["Matemáticas", "Español", "Ciencias"]
print(materias[0]) # Matemáticas (posición 0)
print(materias[1]) # Español
materias.append("Historia") # Agregar al final

# Recorrer la lista
for m in materias:
  print("Estudio:", m)

🔧 Funciones — empaquetar código

Una función es un bloque de código con nombre que puedes reutilizar. Se define con def.

Python — Funciones
def saludar(nombre):
  print("¡Hola,", nombre, "!")

def suma(a, b):
  return a + b

# Usar las funciones
saludar("Regina")
resultado = suma(5, 3)
print("5 + 3 =", resultado)
